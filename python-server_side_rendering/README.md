# Python - Server-Side Rendering

This directory contains my solutions for the Holberton School project
**"Python - Server-Side Rendering"**.

The goal of this project is to practice server-side rendering with Python,
Flask, and Jinja templates. It focuses on generating HTML on the server and
working with dynamic content from templates, JSON, CSV, and SQLite data sources.

## Learning Objectives

- Understand server-side rendering and how it differs from client-side rendering
- Learn the benefits of server-side rendering in web development
- Implement SSR in Python using Flask
- Use the Jinja templating engine to generate dynamic HTML pages
- Read and display data from JSON, CSV, and SQLite databases
- Handle dynamic content and user input in web applications

## Requirements

- Allowed editors: `vi`, `vim`, `emacs`
- Python files will be interpreted with Python 3
- All files must end with a new line
- A `README.md` file at the root of this project folder is mandatory
- Code should be `pycodestyle` compliant
- All files must be executable when required

## Files

- `task_00_intro.py`  
  Generates invitation files from a template and a list of attendee objects.

- `task_01_flask.py`  
  Creates a basic HTML template in Flask.

- `task_02_jinja.py`  
  Creates a dynamic template with loops and conditions in Flask.

- `task_03_json_csv.py`  
  Displays data from JSON or CSV files in Flask.

- `task_04_sqlite.py`  
  Extends dynamic data display to include SQLite.

## Usage

Example:

```bash
python3 task_00_intro.py
```
