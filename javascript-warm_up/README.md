# JavaScript - Warm up

This directory contains my solutions for the Holberton School project
**"JavaScript - Warm up"**.

The goal of this project is to learn the basics of JavaScript through simple
scripts, including variables, data types, conditionals, loops, functions,
objects, arrays, and importing files.

## Requirements

- Allowed editors: `vi`, `vim`, `emacs`
- All files will be interpreted on Ubuntu 20.04 LTS using Node.js `14.x`
- All files must end with a new line
- The first line of all files must be exactly `#!/usr/bin/node`
- A `README.md` file at the root of this project folder is mandatory
- All files must be executable
- Code should be semistandard compliant (`16.x.x`)
- File length will be tested using `wc`

## Learning Objectives

- Why JavaScript programming is amazing
- How to run a JavaScript script
- How to create variables and constants
- The difference between `var`, `let`, and `const`
- The JavaScript data types
- How to use `if` and `if ... else`
- How to use comments
- How to assign values to variables
- How to use `while` and `for` loops
- How to use `break` and `continue`
- What functions are and how to use them
- What a function returns when there is no return statement
- Scope of variables
- Arithmetic operators
- How to manipulate objects and arrays
- How to import a file

## Files

- `0-javascript_is_amazing.js`  
  Prints `JavaScript is amazing` using a constant variable.

- `1-multi_languages.js`  
  Prints three lines with three languages.

- `2-arguments.js`  
  Prints the number of arguments passed to the script.

- `3-value_argument.js`  
  Prints the first argument, or `No argument` if none is passed.

- `4-concat.js`  
  Prints two arguments as a sentence.

- `5-to_integer.js`  
  Prints `My number: <value>` if the argument can be converted to an integer.

- `6-multi_languages_loop.js`  
  Prints three lines using a loop.

- `7-multi_c.js`  
  Prints `C is fun` multiple times.

- `8-square.js`  
  Prints a square using the character `X`.

- `9-add.js`  
  Prints the sum of two integers.

- `10-factorial.js`  
  Computes the factorial of a number.

- `11-second_biggest.js`  
  Prints the second biggest integer in a list of arguments.

- `12-object.js`  
  Updates a value in an object.

- `13-add.js`  
  Exports a function that adds two numbers.

## Usage

Example:

```bash
chmod +x 0-javascript_is_amazing.js
./0-javascript_is_amazing.js
```
