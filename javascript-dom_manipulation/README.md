# JavaScript - DOM Manipulation

This directory contains my solutions for the Holberton School project
**"JavaScript - DOM Manipulation"**.

The goal of this project is to practice DOM selection, DOM updates, events,
and basic network requests using JavaScript in the browser without reloading
the page.

## Requirements

- Allowed editors: All of them
- All files will be interpreted on Chrome browser (version 57.0 or later)
- All files must end with a new line
- A mandatory `README.md` file with meaningful information about the content
  must be placed at the root of the project
- Code should be semistandard compliant
- `var` is not allowed
- HTML should not reload for each action

## Learning Objectives

- How to select HTML elements in JavaScript
- The differences between ID, class, and tag name selectors
- How to modify an HTML element style
- How to get and update HTML element content
- How to modify the DOM
- How to make a request with `XMLHttpRequest`
- How to make a request with Fetch API
- How to listen and bind to DOM events
- How to listen and bind to user events

## Files

- `0-script.js`  
  Updates the header text color to red.

- `1-script.js`  
  Changes the header color when the user clicks on the page.

- `2-script.js`  
  Adds the `.red` class to the header when the page is clicked.

- `3-script.js`  
  Toggles the `.red` and `.green` classes on the header.

- `4-script.js`  
  Adds a new `<li>` element to a list.

- `5-script.js`  
  Changes the text of the header to `New Header!!!`.

- `6-script.js`  
  Fetches and displays a Star Wars character name.

- `7-script.js`  
  Fetches and displays Star Wars movie titles.

- `8-script.js`  
  Fetches and displays a greeting in French.

- `9-script.js`  
  Adds, removes, and clears list items from a list.

- `100-script.js`  
  Advanced task for greeting everybody.

## Usage

Example:

```bash
chmod +x 0-script.js
./0-script.js
```
